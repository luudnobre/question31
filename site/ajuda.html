PARA A ORGANIZAÇÃO

Da pergunta no celular
à conversa no telão.

O aplicativo está pronto em código. Para pessoas em celulares diferentes participarem ao vivo, falta publicar a pasta do site e conectar seu banco compartilhado.

Abrir o HTML sozinho não ativa a conversa online.
A demonstração serve para conhecer as telas neste navegador. Para o evento, siga a configuração abaixo e teste com dois aparelhos.

1. Conheça as telas agora

Abra a demonstração. No menu Organização, use REFORMA31 e a senha fictícia reforma123 para explorar o painel. O nome da pessoa é opcional. As perguntas demonstrativas ficam somente no navegador.

2. Ative o modo online

  1. Na sua conta Cloudflare, crie um banco D1, por exemplo reforma-perguntas. Confira a opção de plano gratuito e suas cotas.
  2. Em Workers & Pages, crie um projeto Pages com upload direto. Envie o conteúdo da pasta site. Os arquivos index.html e _worker.js precisam ficar na raiz do upload.
  3. Nas configurações do projeto Pages, abra Bindings / Vinculações e adicione um banco D1. O nome da variável deve ser exatamente DB. Selecione o banco criado. Configure o ambiente de produção, se houver essa escolha.
  4. Faça um novo deploy da mesma pasta site depois de salvar a vinculação. O banco é preparado automaticamente pelo aplicativo; não é necessário copiar SQL.
  5. Abra o endereço público do projeto. A página inicial deve mostrar Pronto para receber suas perguntas. Se não aparecer, confira o nome DB e o novo deploy. Você pode abrir /api/health no mesmo domínio: o retorno esperado é configured: true.
  6. Entre em Organização → Criar sala. Escolha um nome, código e senha exclusiva para a organização. Guarde a senha: esta versão não tem recuperação por e-mail.

Não há npm, compilação, chave de API ou instalação para publicar. Não é necessário comprar domínio. O código usa recursos de hospedagem e banco sujeitos aos limites do provedor; não habilite recursos pagos se não desejar despesas. Os nomes dos menus podem mudar.

3. Prepare a participação

Um código para o público. Uma senha para você.

Código da sala: sugestão REFORMA31. É esse código que você mostra no evento.

Senha da organização: só quem organiza conhece. Ela protege o painel no servidor.

Senha de participação: opcional. Deixe vazia para as pessoas entrarem apenas pelo código ou link. Se você definir uma, compartilhe com o público.

  1. No painel, clique em Convidar participantes. Distribua o link ou mostre o código no telão.
  2. Quem abrir o link poderá escrever e enviar perguntas sem cadastro. Enviar anonimamente vem ativado; a pessoa pode desativar para informar nome ou apelido.
  3. Acompanhe as perguntas no painel. Elas atualizam aproximadamente a cada 3 segundos, com internet e aba visível.
  4. Abra Telão no projetor. No painel, escolha Exibir no telão. Só a pergunta escolhida fica visível ao público.

4. Teste antes do culto

Abra o link no seu celular usando dados móveis e deixe o painel no computador. Envie uma pergunta, confirme a chegada e selecione para o telão. Confira também a senha, se você ativou uma. Uma simulação em uma única aba não verifica o funcionamento entre aparelhos.

5. Depois do evento

Você pode pausar novos envios, baixar as perguntas em JSON e apagar a sala. A exclusão pede confirmação e remove as perguntas do banco do aplicativo. Não há recuperação da sala pela interface.

Evite dados pessoais nas perguntas. No envio anônimo, não é solicitado nome. Isso não significa anonimato absoluto em relação ao provedor de internet ou de hospedagem, que pode processar metadados técnicos.

Entrega em código, sem publicação em uma conta Cloudflare. Consulte o README para limites, detalhes e referências oficiais. A consulta online à documentação do provedor não esteve disponível nesta execução.
